# 🎓 Student Planner

A comprehensive web-based student planner application designed to help students organize their academic life efficiently. Features include task management, grade tracking, class scheduling, and a calendar view.

## ✨ Features

### 📊 Dashboard
- **Overview at a glance**: See upcoming deadlines, current GPA, today's tasks, and schedule
- **Quick insights**: Visual indicators for urgent tasks and important information
- **Real-time updates**: Dynamic content that updates as you add new data

### ✅ Task Management
- **Add tasks** with due dates, priorities, and subjects
- **Filter tasks** by status (pending, in-progress, completed, overdue) and subject
- **Priority levels**: High, medium, and low priority with color coding
- **Task status tracking**: Toggle between pending → in-progress → completed
- **Overdue detection**: Automatic identification of overdue tasks

### 📈 Grade Tracking
- **Grade calculator**: Automatic percentage and letter grade calculation
- **GPA calculation**: Real-time GPA computation based on credits and grades
- **Credit tracking**: Monitor total credits completed
- **Grade history**: View all grades with dates and assignments

### 📅 Calendar
- **Monthly view** with navigation between months
- **Event display**: Shows tasks due and classes scheduled for each day
- **Today highlighting**: Current date is clearly marked
- **Visual organization**: Clean, easy-to-read calendar layout

### 🕐 Class Schedule
- **Weekly schedule grid**: Visual timetable showing all classes
- **Class details**: Store instructor names, room numbers, and meeting times
- **Multiple days**: Support for classes meeting on different days
- **Time slots**: 8 AM to 8 PM time range coverage

### 💾 Data Management
- **Local storage**: All data saved automatically in browser
- **Export/Import**: Backup and restore your data as JSON files
- **Sample data**: Includes sample data for new users to explore features

## 🚀 Getting Started

### Installation
1. Download all files (`student-planner.html`, `student-planner.css`, `student-planner.js`)
2. Open `student-planner.html` in any modern web browser
3. Start using the planner immediately!

### First Time Setup
1. The app will load with sample data to help you understand the features
2. Navigate through different tabs to explore functionality
3. Add your own tasks, grades, and classes
4. The sample data will be replaced as you add your own information

## 📱 How to Use

### Adding a Task
1. Go to the **Tasks** tab
2. Click **"Add Task"** button
3. Fill in the task details:
   - Title and subject
   - Due date and time
   - Priority level
   - Optional description
4. Click **"Add Task"** to save

### Recording Grades
1. Navigate to the **Grades** tab
2. Click **"Add Grade"** button
3. Enter grade information:
   - Subject and assignment name
   - Score and total points
   - Credit hours for the course
4. The app automatically calculates percentage, letter grade, and updates your GPA

### Setting Up Your Schedule
1. Go to the **Schedule** tab
2. Click **"Add Class"** button
3. Enter class details:
   - Class name and instructor
   - Room location
   - Days of the week
   - Start and end times
4. Your schedule will appear in the grid format

### Using the Calendar
- Navigate between months using the arrow buttons
- View tasks and classes for each day
- Today's date is highlighted in blue
- Events appear as small colored indicators on each date

### Dashboard Overview
The dashboard provides a quick summary of:
- **Upcoming Deadlines**: Next 5 tasks due (with urgent items highlighted)
- **Grade Overview**: Current GPA display
- **Today's Tasks**: Tasks due today
- **Today's Schedule**: Classes scheduled for today
